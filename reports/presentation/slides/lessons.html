Limitations: the real-data evidence is one statistically inferred pair over about 25 labelled days, and because I picked the best of ten pairs using the same labels, the R squared is slightly optimistic. The single-zone model under-predicts peaks. Lessons: the data audit changed the whole project; evaluation design mattered more than model choice; and a half-interval timing detail biased the volume by 40% until synthetic verification caught it. AI: Claude wrote most of the code and drafts; I verified it with tests, known-truth cases and an independent review, which caught real errors — a timestamp unit bug, a split over unlabelled data, and an F1 score that a constant guess could match.
